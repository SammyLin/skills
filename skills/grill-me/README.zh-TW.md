# grill-me

[English](README.md) · 繁體中文

開工前先把計畫拷問一遍，但不會問到你煩。改寫自 Matt Pocock 的 [`grill-with-docs`](https://github.com/mattpocock/skills)：原版會把設計中每個分支都問到底；這一版只問重大的決策。

| | grill-with-docs | grill-me |
| --- | --- | --- |
| 問什麼 | 每個還沒定的決策，直到全部問完 | 只問重大的：難以回頭、影響使用者、金錢或安全、卡住其他決策、真的有分歧、前後矛盾 |
| 其他決策 | 也都問 | 直接給預設值並列出來，你掃一眼，想改再改 |
| 每輪題數 | 當下能問的全部一起問 | 最多四題，目標三輪內結束 |
| 怎麼回答 | 每題自己打字回覆 | 在 Claude Code 的選擇題介面點選，推薦選項排第一（沒有介面時改用編號選項） |
| 邊界情況 | 為了測試會主動編出來 | 只在會改變重大決策時才提 |
| 文件 | 每個術語都寫進術語表，必要時寫 ADR | 難以回頭的取捨才寫 ADR；術語表只收這次真的造成混淆的詞 |
| 結束 | 所有分支問完 | 整理成「已決定、預設值、暫不處理」三段，等你說好才開工 |

在 Claude Code 裡輸入 `/grill-me`，或直接說「幫我拷問這個計畫」。

MIT 授權。改寫自 Matt Pocock 的 skills（MIT），ADR 與術語表格式沿用原作。
